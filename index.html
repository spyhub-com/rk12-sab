Privacy Policy

Data Collected

We collect Roblox User IDs, usernames, place IDs, game names, and execution timestamps. No real-name or contact information is collected.

Data Usage

Collected data is used exclusively for moderation, statistics, and service improvement. Data is never sold or shared with third parties.

Data Storage

Data is stored on JSONBin.io with encrypted API keys. Access is restricted to authorized administrators only.

Data Retention

Execution logs are kept for a maximum of 500 entries. Older entries are automatically removed.

Your Rights

You may request deletion of your data by contacting an administrator through the support system.

Support

Getting Started

Create an account — the first account is automatically Owner. Deploy the worker.js to Cloudflare, then open the script in your executor.

FAQ

Script not working? Make sure JSONBIN_ID and JSONBIN_KEY are set in Cloudflare Secrets.

Ban not applying? The ban applies on the next script execution, not in real-time without a ping loop.

JSONBin full? The bin stores 500 executions max. Older ones are auto-removed.

Contact

Open a support ticket from your user panel after signing in. Premium users get priority response.
